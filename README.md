# Discord Schedule Bot

디스코드 서버에서 일정, 대회, 공지를 관리하는 봇입니다.

## 기능

- 일정 추가, 삭제, 전체보기
- 일정 시작 전 미리알림
- 대회 등록: 분야, 일정, 세부 설명 저장
- 공지: 봇이 지정 채널에 `@everyone` 공지 발송
- 서버 정보 확인
- 채널 생성/삭제
- 역할 생성/지급/회수
- 멤버 추방/차단
- 멤버 입장 환영 메시지
- 메시지 일괄 삭제, 메시지 고정, 반응 추가
- 공개 스레드 생성, 스레드 잠금
- 디스코드 서버 이벤트 생성
- 업다운, 타자게임, 운세, 별명추천, 놀리기
- 명언 등록/랜덤 뽑기
- 반응 투표
- 경고 관리
- 삭제된 채팅 로그 확인
- `@Agent 질문` 형태의 Gemini AI 답변

## 설치

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

`.env` 파일에 봇 토큰을 입력하세요.

```env
DISCORD_TOKEN=...
DEFAULT_TIMEZONE=Asia/Seoul
GEMINI_API_KEY=...
GEMINI_MODEL=gemini-3.5-flash
AI_ALLOWED_CHANNEL_IDS=123456789012345678
BOT_OWNER_IDS=123456789012345678
```

`BOT_OWNER_IDS`에는 봇 최고관리자 Discord 사용자 ID를 넣습니다.
처음에는 여기에 등록된 사람만 `/권한주기`로 봇관리자를 추가할 수 있습니다. 여러 명이면 쉼표로 구분합니다.
`AI_ALLOWED_CHANNEL_IDS`를 비워두면 모든 채널에서 `@Agent` AI 질문이 작동하고, 넣으면 해당 채널들에서만 작동합니다.
실행 중 모델 변경은 owner 전용 `/ai모델` 명령어로 할 수 있습니다.

## Discord Developer Portal 설정

Bot 설정에서 아래 권한을 켜세요.

- `SERVER MEMBERS INTENT`를 켜세요. 입장 환영 메시지에 필요합니다.
- `MESSAGE CONTENT INTENT`는 필수는 아니지만 켜두면 운영 중 확장에 유리합니다.
- 타자게임과 삭제로그를 사용하려면 `MESSAGE CONTENT INTENT`를 켜세요.
- `@Agent 질문` Gemini 응답도 `MESSAGE CONTENT INTENT`가 필요합니다.
- 초대 URL 권한: `bot`, `applications.commands`
- 봇 권한:
  - `Manage Server`
  - `Manage Roles`
  - `Manage Channels`
  - `Kick Members`
  - `Ban Members`
  - `Moderate Members`
  - `Manage Events`
  - `Create Events`
  - `Send Messages`
  - `Create Public Threads`
  - `Manage Messages`
  - `Manage Threads`
  - `Embed Links`
  - `Read Message History`
  - `Mention Everyone`
  - `Add Reactions`
  - `Use Slash Commands`

봇 내부 관리 권한은 `.env`의 `BOT_OWNER_IDS`와 `/권한주기`로 관리합니다.
단, 봇 자체의 권한과 역할 순서는 디스코드가 강제하므로 역할 지급/추방 같은 작업은 봇 역할이 대상보다 위에 있어야 합니다.


## Gemini AI

채널에서 `@Agent 질문내용`처럼 멘션하면 Gemini가 답합니다.
또는 봇이 보낸 답변에 답글로 이어서 말해도 최근 문맥을 참고해서 답합니다.

예:

```text
@Agent 오늘 일정 요약해줘
@Agent 공지 문구 자연스럽게 써줘
```

## 명령어

### 일반

`/명령어`

- 봇 명령어 목록을 카테고리별로 보여줍니다.

`/내아이디`

- 내 Discord 사용자 ID와 봇 오너 등록 여부를 확인합니다.

`/업다운`

- 1~100 숫자 맞히기 게임을 시작하거나 추측합니다.

`/타자게임`

- 지정한 문장을 가장 빨리 정확히 치는 사람이 승리합니다.

`/별명추천`

- 유저에게 랜덤 별명을 추천합니다.

`/명언랜덤`

- 등록된 서버 명언을 랜덤으로 보여줍니다.

`/오늘의운세`

- 랜덤 운세와 점수를 보여줍니다.

`/놀리기`

- 조금 더 독한 랜덤 장난 멘트를 보냅니다.

`/투표`

- 선택지를 반응으로 투표할 수 있게 만듭니다.

### Owner 전용

`/권한주기`

- owner가 유저에게 봇관리자 권한을 줍니다.

`/권한회수`

- owner가 유저의 봇관리자 권한을 회수합니다.

`/권한목록`

- owner와 봇관리자 목록을 보여줍니다.

`/db테이블`

- DB에서 관리 가능한 테이블 목록을 봅니다.

`/db조회`

- DB 테이블 데이터를 조회합니다.

`/db삭제`

- `db조회`에 표시되는 `row_id`로 한 줄을 삭제합니다.

`/db초기화`

- 지정한 DB 테이블을 비웁니다. 확인 값에 `초기화`를 입력해야 실행됩니다.

`/ai모델목록`

- 선택 가능한 Gemini 모델과 현재 모델을 봅니다.
- 현재 코드에는 `gemini-3.5-flash`, `gemini-3.5-pro`, `gemini-3-flash`, `gemini-3.1-pro`, `gemini-3.1-flash-lite`, `gemini-2.5-flash`, `gemini-2.5-flash-lite`, `gemini-2.5-pro`를 넣어두었습니다.

`/ai모델`

- owner가 현재 Gemini 모델을 변경합니다.

### 일정 관리

`/일정추가`

- 제목
- 시작: `6월8일 14시`, `2026-06-08 14:00`, `6/8 14:00`
- 종료: `6월8일 16시`, `2026-06-08 16:00`
- 종일: true/false
- 미리알림분: 예: `30`
- 설명: 선택

`/일정삭제`

- 일정 ID로 삭제합니다.

`/일정전체보기`

- 서버에 등록된 일정을 시간순으로 보여줍니다.

`/일정템플릿`

- 일정 추가에 사용할 입력 예시를 보여줍니다.

### 관리자

`/공지`

- 지정한 채널에 `@everyone` 멘션과 함께 공지를 보냅니다.
- 한 줄 공지에 사용합니다.
- 명령어 사용자는 owner 또는 봇관리자 권한이 필요합니다.

`/공지작성`

- 여러 줄 공지를 작성 창에 입력해서 보냅니다.
- 명령어 사용자는 owner 또는 봇관리자 권한이 필요합니다.

`/채팅도배`

- 현재 채널에 같은 문자를 여러 번 보냅니다.
- 최대 100회까지 가능합니다.
- 명령어 사용자는 owner 또는 봇관리자 권한이 필요합니다.

`/명언등록`

- 유저의 명언을 저장합니다.
- owner 또는 봇관리자 권한이 필요합니다.

`/경고`

- 유저에게 경고를 부여합니다.
- 경고가 3회 누적되면 자동으로 강퇴합니다.
- 유저가 서버에서 나가면 경고 기록은 자동 삭제됩니다.
- owner 또는 봇관리자 권한이 필요합니다.

`/경고목록`

- 유저별 경고를 확인합니다.
- owner 또는 봇관리자 권한이 필요합니다.

`/경고삭제`

- 경고 ID로 경고를 삭제합니다.
- owner 또는 봇관리자 권한이 필요합니다.

`/삭제로그`

- 봇이 온라인인 동안 삭제된 최근 채팅을 확인합니다.
- 결과는 채널 전체에 보입니다.
- owner 또는 봇관리자 권한이 필요합니다.

### 서버 관리

`/서버정보`

- 서버 ID, 소유자, 멤버 수, 채널 수, 역할 수를 보여줍니다.

`/채널만들기`

- 텍스트 채널을 생성합니다.

`/채널삭제`

- 텍스트 채널을 삭제합니다.

`/역할만들기`

- 역할을 생성합니다. 색상은 `#5865F2` 형식으로 입력할 수 있습니다.
- owner 또는 봇관리자 권한이 필요합니다.

`/역할지급`

- 멤버에게 역할을 지급합니다.
- owner 또는 봇관리자 권한이 필요합니다.

`/역할회수`

- 멤버에게서 역할을 회수합니다.
- owner 또는 봇관리자 권한이 필요합니다.

`/멤버추방`

- 멤버를 서버에서 추방합니다.
- owner 또는 봇관리자 권한이 필요합니다.

`/멤버차단`

- 멤버를 서버에서 차단합니다.
- owner 또는 봇관리자 권한이 필요합니다.

`/채팅금지`

- 멤버를 지정한 시간 동안 타임아웃합니다.
- 시간은 1~10080분까지 가능합니다.
- owner 또는 봇관리자 권한이 필요합니다.

`/채팅허용`

- 멤버의 타임아웃을 해제합니다.
- owner 또는 봇관리자 권한이 필요합니다.

### 메시지/스레드

`/메시지삭제`

- 현재 채널의 최근 메시지를 1~100개 삭제합니다.

`/메시지고정`

- 채널과 메시지 ID를 입력해 메시지를 고정합니다.

`/반응추가`

- 채널과 메시지 ID를 입력해 이모지 반응을 추가합니다.

`/스레드만들기`

- 현재 텍스트 채널에 공개 스레드를 만듭니다.

`/스레드잠금`

- 스레드를 잠그거나 잠금 해제합니다.

### 서버 이벤트

`/이벤트만들기`

- 디스코드 서버 이벤트를 생성합니다.

### 대회

`/대회등록`

- 분야
- 제목
- 시작, 종료, 종일, 미리알림분
- 세부 설명
- 등록된 대회는 일정에도 같이 저장됩니다.

## 날짜 입력 예시

- `6월8일 14시`
- `6월 8일 14시 30분`
- `2026-06-08 14:00`
- `6/8 14:00`
- `6/8`

연도를 생략하면 현재 연도를 사용합니다.
